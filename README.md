# 토닥토닥 첫 낱말 (Toddler First Words) 🎈

> **2~4세 영유아를 위한 무광고·안심 터치 그림 소리 놀이 앱**  
> 아이가 안심하고 화면을 만지며 말문이 트일 수 있도록 설계된 아동 친화적 첫 낱말 학습 PWA & 모바일 웹 애플리케이션입니다.

---

## 🌟 주요 특징 (Core Features)

### 1. 🎮 즐겁고 부담 없는 낱말 퀴즈 놀이
- **2단계 몰입 씬 (Scene A → Scene B)**:
  - **소개 씬**: 커다란 글자가 통통 튀며 귀로 단어를 먼저 듣습니다.
  - **찾기 씬**: 방에서 둥둥 떠다니는 귀여운 3D 그림 스티커 중 맞는 카드를 톡 터치합니다.
- **착한 피드백 (No ✕ / No Buzzers)**:
  - 틀려도 빨간 X 표시나 거친 경고음이 전혀 없습니다.
  - 젤리처럼 살짝 흔들리며 *"이건 바나나야. 사과는 어디에 있을까?"* 하고 친절하고 다정하게 유도합니다.
- **정답 환호 & 축하**:
  - 반짝이는 왕관과 꽃가루 파티클, 칭찬 음성이 끝나기 전까지 화면이 성급하게 넘어가지 않고 여유롭게 축하합니다.
- **아이 맞춤 적응형 난이도**:
  - 아이의 성장에 맞춰 카드 수가 2개 → 3개 → 4개로 자동 조절되거나 보호자가 원하는 개수로 고정할 수 있습니다.

### 2. 🎙️ 엄마·아빠 목소리 녹음실 (Parent Voice Studio)
- **부모 목소리 우선 재생**:
  - 기계음(TTS) 대신 부모님의 따뜻하고 다정한 실제 목소리를 직접 녹음해 들려줄 수 있습니다.
- **정답 칭찬 목소리 녹음 (4종)**:
  - *"딩동댕! 정말 잘했어!"*, *"우와! 우리 아기 최고야!"* 등 아이가 좋아하는 부모님의 환호 소리를 녹음하여 정답 시 랜덤으로 재생합니다.
- **42개 전체 낱말 녹음 지원**:
  - 동물, 음식, 탈것, 신체, 사물, 자연 등 원하는 단어를 1~3초간 밝게 녹음할 수 있습니다.
- **완전 오프라인 영구 보관 (IndexedDB)**:
  - 브라우저 내 IndexedDB를 활용하여 인터넷 연결이 없는 환경(비행기 모드 등)에서도 끊김 없이 재생됩니다.

### 3. 📖 낱말 도감 (Explore) & 🌟 스티커북 (Stickers)
- **낱말 도감**:
  - 6개 카테고리 42개 낱말 카드를 마음껏 만져보며 고화질 3D 그림과 발음을 함께 학습합니다.
- **스티커북**:
  - 한 라운드(5문제)를 완료할 때마다 새로운 스티커를 보상으로 받아 20칸 스티커판을 채워갑니다.
  - 모은 스티커를 톡 누르면 언제든 다시 복습할 수 있습니다.

### 4. 🛡️ 안심 보호자 설정 (Parent Gate)
- **3초 롱프레스 잠금**:
  - 아이의 무분별한 설정 변경을 방지하기 위해 3초 동안 꾹 누르고 있어야 보호자 화면이 열립니다.
- **일일 이용시간 타이머 & 취침 유도**:
  - 10분 / 20분 / 30분 / 무제한 설정 가능.
  - 설정한 시간이 지나면 현재 문제 종료 후 *"오늘은 여기까지! 내일 또 만나요~"* 밤하늘 화면으로 전환되어 자연스럽게 기기 사용을 마무리합니다.
- **출제 카테고리 선택 & 언어 전환**:
  - 원하는 주제(최소 2개 이상)만 골라 출제하거나 한국어 🇰🇷 / 영어 🇺🇸 발음 모드를 바꿀 수 있습니다.

### 5. 📱 스마트폰 및 터치 최적화
- **실수 터치 방지**:
  - 화면 확대(더블 탭/핀치 줌), 텍스트 드래그 선택, 길게 눌러 나오는 브라우저 컨텍스트 메뉴를 모두 원천 차단했습니다.
- **140px 이상 대형 터치 타깃**:
  - 소근육이 발달 중인 영유아도 손쉽게 터치할 수 있도록 넉넉한 히트박스를 적용했습니다.
- **모바일 완벽 좌우 대칭 레이아웃**:
  - 스마트폰 세로 화면에서도 카드가 한쪽으로 치우치거나 잘리지 않고 정확한 중앙 대칭 여백을 유지합니다.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 사용 기술 |
| :--- | :--- |
| **Frontend** | React 19, TypeScript, Vite |
| **Styling** | Tailwind CSS v4 |
| **Animation** | Motion (Framer Motion) |
| **Audio** | Web Audio API, MediaRecorder API, Web Speech API |
| **Storage** | IndexedDB (Parent Voice Blob), Zustand + localStorage (State) |
| **Mobile & PWA** | Vite PWA (Service Worker, Offline Cache, Manifest), Capacitor |
| **Icons & Effects** | Lucide React, Canvas Confetti |

## 🚀 시작하기 (Getting Started)

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 3. 프로덕션 빌드
```bash
npm run build
```

### 4. 타입 및 코드 검사
```bash
npm run lint
```

## 👶 영유아 안심 설계 원칙 (Toddler Design Constitution)

1. **무광고, 무과금 (Zero Ads, Zero IAP)**: 아이가 만지다 광고를 누르거나 결제창이 뜰 위험이 전혀 없습니다.
2. **부정적 피드백 지양**: 틀려도 실패감을 주지 않고 아이 스스로 탐색할 수 있도록 따뜻하게 안내합니다.
3. **직관적인 비언어적 UI**: 글자를 읽지 못하는 2~4세 아이도 그림과 소리만으로 모든 조작이 가능합니다.
4. **시력 및 수면 보호**: 화려한 깜빡임이나 자극적인 음향을 배제하고, 설정된 시간이 지나면 차분한 밤하늘 화면으로 잠자리를 유도합니다.
